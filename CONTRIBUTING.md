# Contributing

Thanks for helping improve Levatain-MD.

1. Fork the repo and create a branch (`feat/my-plugin`, `fix/menu-thumb`).
2. Install: `npm install` (Node 20+, ffmpeg installed on the system).
3. Copy `.env.example` to `.env` and fill the minimum variables.
4. New commands go in `plugins/<category>/`, see "Adding a New Plugin/Command" in the README.
5. Run `npm run check` before opening a pull request.
6. Keep commits small with clear messages, for example `fix: menu video fallback`.
