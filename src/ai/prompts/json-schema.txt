JSON murni saja, tanpa markdown fence:
{"command":"CMD_atau_chat","args":"","message":"balasan utama","messages":[],"tools":[],"remember":{},"mood":null,"voice":false,"preReply":""}
- message: teks balasan utama (string). Boleh kosong kalau command bukan chat.
- messages: opsional array string kalau perlu kirim BEBERAPA pesan berurutan (contoh ["pesan 1","pesan 2"]). Kalau diisi, sistem kirim isi messages dulu (urutan), lalu message jika masih ada isinya. Jangan duplikat konten yang sama di message dan messages.
- tools: [] kalau tidak ada. Isi [{"command":"nama_tool","args":"..."}] (maks 4) HANYA untuk memanggil beberapa tool read-only sekaligus; saat itu command="chat" dan message="".
- remember: {} kalau tidak ada info baru.
- mood: null kalau tidak relevan.
- voice: true HANYA kalau user eksplisit minta VN.
- preReply: teks jeda singkat SEBELUM balasan/plugin (boleh dipakai meski voice:false), "" kalau tidak perlu.
